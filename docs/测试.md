# 测试

回归套件在 `test/`（**入仓库**）。

```bash
cd plugins/Alias-Plugin
pnpm test                    # = node test/run.mjs，任意 cwd 可跑
pnpm test -- --list          # 只列套件
pnpm test -- --filter=index  # 只跑文件名含 index 的
```

不启动 bot：直接跑真实生产代码路径；**断言失败 exit 1**；**缺前置打印「跳过」并 exit 0**。

## 规范

- 命名 `<主题>.test.mjs`（写被测行为）
- 路径一律经 `test/_helper.mjs` 推导（`pluginRoot` / `mod()` / `tmpDir`），**禁止裸相对字面量与盘符绝对路径**
- 临时产物只写 `test/.test-tmp/`（gitignore）；夹具经 `writeFixture()` 生成并用 `ALIAS_DATA_DIR` 指向它，
  **不碰仓库的 `data/`**
- 框架全局（`logger`）用 `installFrameworkStubs()` 的内存实现
- **断言必须能真的失败**：新增套件先临时改坏代码确认转红，再恢复入库

## 公共设施（`test/_helper.mjs`）

| 导出 | 用途 |
|------|------|
| `pluginRoot` / `appRoot` / `dataDir` / `tmpDir` / `testDir` | 路径推导（由 `import.meta.url` 得出） |
| `mod(relPath)` | 生产代码的 file URL，供套件 `import` |
| `requireAliasData()` / `hasAliasData()` | 数据前置 |
| `skip(reason)` | 打印「跳过」并 exit 0 |
| `checker()` | 断言计数与汇总退出 |
| `installFrameworkStubs()` | `logger` 桩（可收集日志） |
| `writeFixture(name, doc)` | 写别名数据夹具，返回目录 |

## 套件

| 套件 | 覆盖 | 前置 |
|------|------|------|
| `normalize.test.mjs` | 归一化（空白 / 大小写 / 间隔号 / 包裹符号 / 花括号保留）、别名串拆分（逗号 / 顿号 / 数组 / 自我引用剔除 / 去重） | 无 |
| `index-build.test.mjs` | 双向映射、非法条目跳过与计数、同键多命中、来源优先级覆盖、游戏与实体隔离、变体生成、边界 | 无 |
| `data-file.test.mjs` | 正常读取、文件缺失、JSON 坏掉、结构异常、字段非法、来源元数据、路径解析 | 无（夹具） |
| `service-api.test.mjs` | `lookup` 三态、别名反查、过滤、`variants`、`list`（含副本语义）、`status` 安全性、`reload` / `reset`、数据缺失降级 | data/alias.json |
| `app-contract.test.mjs` | `apps/` 每个文件恰好一个类导出、不注册 rule/task/handler、继承框架基类、`index.js` 只装配、服务不写文件 | 无 |
| `smoke-imports.test.mjs` | 全部模块可加载、导出面齐全、常量表口径（游戏 / 实体 / 来源 / 优先级） | 无 |

数据未生成时 `service-api` 会跳过——新克隆的仓库不会因此变红。

## 不入库

留在开发机的一次性排查脚本（`data/custom.json` 覆盖关系排查、单条别名溯源等）不写进 `test/`：
它们没有断言与退出码，作为回归只会「永远通过」。需要时放 `test/.test-tmp/` 跑完即删。
