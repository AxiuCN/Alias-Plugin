# 测试

回归套件在 `test/`（**入仓库**）。

```bash
cd plugins/Alias-Plugin
pnpm test                    # = node test/run.mjs，任意 cwd 可跑
pnpm test -- --list          # 只列套件
pnpm test -- --filter=index  # 只跑文件名含 index 的
```

不启动 bot：直接跑真实生产代码路径；**断言失败 exit 1**；**缺前置打印「跳过」并 exit 0**。

## 规范

- 命名 `<主题>.test.mjs`（写被测行为）
- 路径一律经 `test/_helper.mjs` 推导（`pluginRoot` / `mod()` / `tmpDir`），**禁止裸相对字面量与盘符绝对路径**
- 上游一律用夹具：`writeFixtureTree()` 在 `test/.test-tmp/` 下造假的 miao / ZZZ 目录树，
  再用 `useFixtureTree()` 设 `ALIAS_MIAO_DIR` / `ALIAS_ZZZ_DIR`。
  **绝不读写真实的 miao / ZZZ 目录**（尤其不写它们的 `config/`）
- 夹具目录在写入前会被清空，避免上一轮的残留文件影响断言
- 框架全局（`logger`）用 `installFrameworkStubs()` 的内存实现
- **断言必须能真的失败**：新增套件先临时改坏代码确认转红，再恢复入库

## 公共设施（`test/_helper.mjs`）

| 导出 | 用途 |
|------|------|
| `pluginRoot` / `appRoot` / `tmpDir` / `testDir` | 路径推导（由 `import.meta.url` 得出） |
| `mod(relPath)` | 生产代码的 file URL，供套件 `import` |
| `skip(reason)` | 打印「跳过」并 exit 0 |
| `checker()` | 断言计数与汇总退出 |
| `installFrameworkStubs()` | `logger` 桩（可收集日志） |
| `writeFixtureTree(name, opts)` | 造假 miao / ZZZ 目录树，返回 `{ miao, zzz }` |
| `useFixtureTree(dirs)` / `clearFixtureTree()` | 设置 / 清除上游环境变量 |

## 套件

| 套件 | 覆盖 | 前置 |
|------|------|------|
| `normalize.test.mjs` | 归一化（空白 / 大小写 / 间隔号 / 包裹符号 / 花括号保留）、别名串拆分 | 无 |
| `alias-sources.test.mjs` | 三种导出名都要读到（`alias`/`abbr`/`setAbbr`）、ZZZ 数组形态、仓库自带、cfg 行解析与坏行跳过、上游缺失降级 | 夹具 |
| `alias-index.test.mjs` | 双向可查、位置取舍（实例自定义压过预设、自带压过预设）、档次取舍（中文压过外文、日韩英同级）、位置优先于档次、跨游戏/实体隔离、同原名多别名、非法条目计数 | 无 |
| `service-api.test.mjs` | `lookup` 三态、实例自定义运行期生效且只来自本机、自带别名、过滤、`variants`、`list` 归组与副本语义、`status` 安全性、`reload`、上游缺失降级 | 夹具 |
| `app-contract.test.mjs` | apps 单类导出、不注册命令、index.js 只装配、服务与数据层不写文件、**历史结构（生成物 / HotReload）不得复活** | 无 |
| `smoke-imports.test.mjs` | 全部模块可加载、导出面齐全、常量口径（游戏 / 实体 / 档次 / 位置 / 文件清单） | 无 |

## 不入库

一次性排查脚本（别名溯源、覆盖关系排查等）不进 `test/`：它们没有断言与退出码，
作为回归只会「永远通过」。需要时放 `test/.test-tmp/` 跑完即删。
