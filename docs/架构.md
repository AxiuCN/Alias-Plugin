# 架构

## 定位

别名数据层：把「别名 ↔ 原名」的关系收在一处，对外开放查询。**不接管业务**——
图库目录检查、页面路由、业务归一、加权评分、用户命令都归调用方。

## 目录分层

```
Alias-Plugin/
├── index.js              入口：日志头 + 装配 apps/（无业务逻辑、不准备数据）
├── apps/
│   └── aliasService.js   能力出口：一个继承 plugin 的类，挂载查询方法（无 rule / task）
├── modules/
│   └── AliasService.js   业务出口：查询、清单、状态、重建、降级
├── model/
│   ├── UpstreamFiles.js  miao / ZZZ 文件清单（常量）
│   ├── AliasSources.js   运行期读本机：预设别名、仓库自带、实例自定义
│   └── AliasIndex.js     索引构建与查询（纯内存，零 I/O）
├── components/
│   ├── normalize.js      文本归一化与别名串拆分（纯函数）
│   ├── entityNames.js    游戏 / 实体 / 名字档次的定义
│   └── config.js         pluginRoot
├── data/aliases.json     仓库自带别名（入库；Action 以后把扒到的别名也写这里）
├── defSet/ + config/     配置三层结构（当前只留插件路径推导，暂无需配置项）
├── test/                 回归套件
└── docs/
```

依赖方向单向：`index.js → apps → modules → model → components`。`components` 不 import 上层。

## 数据流：运行期读本机，没有共享生成物

```
miao-plugin/resources/**/alias.js     预设别名（基础，人人都有）     位置 1
ZZZ-Plugin/defSet/alias.yaml          预设别名（选装，没装就没有 zzz） 位置 1
Alias-Plugin/data/aliases.json        仓库自带别名                    位置 2
miao-plugin/config/alias_{gs,sr}.cfg  实例自定义别名                  位置 3
        │
        └─ model/AliasSources.js 读 → model/AliasIndex.js 合成 → modules/AliasService.js 查询
```

**关键点**：实例自定义别名是**各实例私有**的运行期数据（`#喵喵别名设置` 写的），
只在本机读取、绝不写进仓库文件；`data/aliases.json` 只放本仓库自己维护的公开别名
（以后 GitHub Action 扒到的别名也写它，运行期入口已经就位，无需改代码）。

## 数据模型

一层索引 + 一个位置字段：

```
standard  = { name, aliases:Set, position, tier, game, entity }
位置      ：custom(3) > overlay(2) > preset(1)
档次      ：由 standard.name 的语言决定
索引键    ：归一化后的写法 → 该写法指向的 standard 列表
```

`data/aliases.json`（入库，仓库自带）：

```json
{ "version": 1, "aliases": [
  { "canonical": "旅行者", "alias": "空", "game": "gi", "entity": "character" }
] }
```

## 优先级

两个维度，**顺序固定**：

1. **位置**：实例自定义 > 仓库自带 > miao/ZZZ 预设
   —— 与 miao 自身语义一致（`CustomAlias.applyToMeta` 直接改写 `meta.alias[key]`）
2. **档次**：中文原名 > 外文原名
   —— 原名只有中文 / 英文 / 日文 / 韩文四种，**日韩英同级**（`{NICKNAME}` 归外文原名）

取舍**限定在同一个 `(游戏, 实体)` 内**：跨游戏、跨实体的同名写法互不干扰。
同一原名的多个别名全部保留；同位置同档次的多个原名共存，如何取舍归调用方。

## 归一化

只解决「同一个词的不同写法落到同一个键」：去空白 → 去间隔号（`·・•‧`）→ 去包裹符号
（`「」『』《》【】（）()[]""''`）→ 小写。**刻意不去花括号**（`{NICKNAME}` 是星铁开拓者的原名）。

不做：命令前缀剥离、简繁转换、模糊匹配、目录名匹配。

## 缓存与刷新

- **不缓存**：每次查询都重新读盘并合成（782 个原名 / 3771 个关键词 / 约 77ms）。
  别名表规模不大，而"绝不返回过期数据"比省这点开销重要——实例自定义别名随时可能被
  miao 的命令改写，重算天然就是热更新，也不需要文件监听与缓存合法性判断。
- 需要显式刷新时调 `reload()`（语义上就是重新读一遍）。
