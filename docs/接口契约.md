# 接口契约

对外出口只有一个模块：`modules/AliasService.js`。所有查询函数都是 **async**，且**不抛错**——
插件缺失 / 文件损坏 / 名字解析不到一律降级，调用方不需要 try/catch。

优先级的唯一依据：**位置**（实例自定义 > 仓库自带 > 预设）优先，同位置层内再看**档次**
（中文原名 > 外文原名）。

## lookup(keyword, opts?)

关键词 → 原名。

```js
await lookup('核桃', { game: 'gi', entity: 'character' })
```

| 返回字段 | 说明 |
|----------|------|
| `status` | `exact`（唯一原名）/ `ambiguous`（多命中）/ `none`（未命中） |
| `canonical` | `exact` 时为原名；其余为 `null` |
| `candidates` | 候选数组，元素见下表，已按位置 → 档次排序 |
| `keyword` / `normalized` | 入参原文 / 归一化后命中的原名 |

`candidates` 元素：

| 字段 | 说明 |
|------|------|
| `canonical` | 原名 |
| `game` / `entity` | 归属 |
| `tier` / `tierLabel` | 档次：`zh-canonical`（中文原名）/ `xx-canonical`（外文原名） |
| `position` / `positionLabel` | 位置：`custom`(3) / `overlay`(2) / `preset`(1) |
| `matchedBy` | 本次按原名（`canonical`）还是按别名（`alias`）命中 |

- `opts.game` / `opts.entity` 可选；非法值被忽略（退化为不过滤）
- **歧义不替调用方决定**：`ambiguous` 时把全部候选给出
- 同名写法跨游戏 / 跨实体互不干扰，取舍只在同一 `(游戏, 实体)` 内发生

## variants(keyword, opts?)

关键词的全部写法，**第一个固定为入参原文**：

```js
await variants('胡桃')   // → ['胡桃', '核桃', '桃', '往生堂主', ...]
```

供「一次要搜多个写法」的场景（搜索类调用方）。未命中时只回原文；空关键词回 `[]`。

## list(opts?)

别名清单，**按原名归组**（每次返回新对象与新的别名数组，改动不污染数据）。

```js
await list({ game: 'gi', entity: 'weapon', limit: 20 })
// → [{ canonical: '雾切之回光', alias: ['雾切'], game: 'gi', entity: 'weapon',
//      tier: 'zh-canonical', position: 1 }]
```

## status()

服务自检，**不回显服务器绝对路径、不回显实例私有别名内容**：

| 字段 | 说明 |
|------|------|
| `ok` | 表非空且构建无错 |
| `error` | 构建失败原因（正常时为空串） |
| `standards` / `keywords` / `aliases` | 原名数 / 索引键数 / 别名条数 |
| `skipped` / `unresolvedCustom` | 跳过字段数 / 实例自定义里未匹配到已收录名字的行数 |
| `loaded` | `{ miao, zzz }` 上游是否在场 |
| `counts` | `{ preset, overlay, custom }` 各位置来源的条目数 |
| `byGame` / `byEntity` / `byTier` / `byPosition` | 各维度分布（按**原名**计） |
| `builtAt` / `buildCostMs` | 本次构建时间与耗时 |
| `stats` | `lookups / hits / misses / ambiguous / rebuilds` |

## reload()

`await reload()` → `{ ok, error, count }`。因为不做缓存，它的语义就是"重新读一遍"。

## 常量

`components/entityNames.js` 是游戏 / 实体 / 档次的**唯一定义处**：

```js
GAMES     // { gi: '原神', hsr: '星铁', zzz: '绝区零' }
ENTITIES  // { character: '角色', weapon: '武器', artifact: '圣遗物' }
TIERS     // { 'zh-canonical': {level:1,label:'中文原名'}, 'xx-canonical': {level:2,label:'外文原名'} }
tierOf(name)   // 原名 → 档次（只看含不含中文）
tierLevel(id)  // 档次 → 级别（越小越优先）
```

`model/AliasIndex.js` 的 `POSITIONS` 是位置层级：`custom(3) > overlay(2) > preset(1)`。

## 降级契约

| 情形 | 行为 |
|------|------|
| miao-plugin 未安装 | 预设为空表，`loaded.miao === false`，只告警一行；仓库自带别名仍可用 |
| ZZZ-Plugin 未安装 | zzz 维度为空，`loaded.zzz === false`；绝区零用不上时无影响 |
| 实例自定义 cfg 不存在 | 该位置层为空，正常 |
| cfg 单行损坏 / 名字解析不到 | 跳过该行并计数，不影响其他行 |
| 上游 alias.js 解析失败 | 跳过该文件，其余照常 |
| 自带 `data/aliases.json` 损坏 | 跳过该文件并告警 |

**任何情况下都不阻断 bot 启动，也不影响其它插件加载。**
