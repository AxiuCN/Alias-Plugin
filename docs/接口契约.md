# 接口契约

对外出口只有一个模块：`modules/AliasService.js`。所有函数**不抛错**——
数据缺失 / 解析失败一律降级，调用方不需要 try/catch。

优先级的唯一依据是**标准名的档次**（中文原名 > 外文原名），与来源无关。

## lookup(keyword, opts?)

关键词 → 标准名。

```js
lookup('核桃', { game: 'gi', entity: 'character' })
```

| 返回字段 | 说明 |
|----------|------|
| `status` | `exact`（唯一标准名）/ `ambiguous`（多命中）/ `none`（未命中） |
| `canonical` | `exact` 时为标准名；其余为 `null` |
| `candidates` | 候选数组，元素为 `{ canonical, game, entity, tier, tierLabel, matchedBy }`，已按档次排序 |
| `keyword` | 入参原文 |
| `normalized` | 归一化后的键（排查用） |

- `tier` / `tierLabel`：候选标准名的档次 —— `zh-canonical`（中文原名）/ `xx-canonical`（外文原名）
- `matchedBy`：`canonical`（入参本身是标准名）/ `alias`（入参是别名）—— 它是**命中方式**，
  与档次无关（档次描述的是标准名）
- `opts.game` / `opts.entity` 可选；非法值被忽略（退化为不过滤）
- **歧义不替调用方决定**：`ambiguous` 时把全部候选给出，怎么用由调用方定
- 同名写法跨游戏 / 跨实体互不干扰，取舍只在同一 `(游戏, 实体)` 内发生

## variants(keyword, opts?)

关键词的全部写法，**第一个固定为入参原文**：

```js
variants('胡桃')   // → ['胡桃', '核桃', '桃', ...]
```

供「一次要搜多个写法」的场景（搜索类调用方）。未命中时只回原文；空关键词回 `[]`。

## list(opts?)

别名清单，**按标准名归组**（返回副本，改动 — 包括 `alias` 数组 — 不污染索引）。

```js
list({ game: 'gi', entity: 'weapon', limit: 20 })
// → [{ canonical: '雾切之回光', alias: ['雾切'], game: 'gi', entity: 'weapon', tier: 'zh-canonical' }]
```

| 字段 | 说明 |
|------|------|
| `canonical` | 标准名（同一标准名只出现一次） |
| `alias` | 该标准名的别名数组 |
| `game` / `entity` | 归属 |
| `tier` | 标准名档次 |

## status()

服务自检，**不回显服务器绝对路径**：

| 字段 | 说明 |
|------|------|
| `ok` | 数据可用且非空 |
| `error` | 降级原因（可用时为空串） |
| `entries` | 双向展开后的映射行数（标准名 ↔ 别名 各一条） |
| `canonical` / `keywords` | 标准名去重数 / 索引键数（归一化写法数） |
| `skipped` / `deduped` | 跳过的非法条目数 / 去重掉的条目数 |
| `byGame` / `byTier` | 各游戏映射行数 / 各档次标准名数（`byTier` 合计 = `entries ÷ 2`） |
| `builtAt` / `dataUpdatedAt` | 索引构建时间 / 数据文件修改时间 |
| `upstream` | `source.json` 里的上游指纹 |
| `stats` | `lookups / hits / misses / ambiguous / reloads` 计数 |
| `watch` | 热重载监听状态 |

## reload() / reset() / stopReload()

- `reload()` → `{ ok, error, count }`，重建索引（数据文件变更后由热重载自动调用）
- `reset()` 清缓存，下次查询自动重建（测试用）
- `stopReload()` 停止数据文件监听（测试收尾用）

## 常量

`components/sources.js` 是游戏 / 实体 / 档次的**唯一定义处**：

```js
GAMES     // { gi: '原神', hsr: '星铁', zzz: '绝区零' }
ENTITIES  // { character: '角色', weapon: '武器', artifact: '圣遗物' }
TIERS     // { 'zh-canonical': {level:1,label:'中文原名'}, 'xx-canonical': {level:2,label:'外文原名'} }
isZhName(v)      // 是否含中日韩表意文字
tierOf(canonical) // 标准名 → 档次
tierLevel(id)     // 档次 → 级别（越小越优先）
```

## 降级契约

| 情形 | 行为 |
|------|------|
| `data/alias.json` 不存在 | 查询返回 `none`，`status().ok === false` 且带原因 |
| JSON 解析失败 / 结构异常 | 同上，`logger.warn` 一次 |
| 条目字段缺失或值非法 | 该条跳过并计数（`status().skipped`） |
| 上游文件缺失（生成期） | 告警跳过该文件，其余照常生成 |
| `yaml` 模块不可用（生成期） | 跳过 YAML 来源，其余照常生成 |

**任何情况下都不阻断 bot 启动，也不影响其它插件加载。**
